# История версий

## 5.1
Исправления по первым запускам 5.0.

- **В папке загрузок — только готовые файлы.** Недокачанные части (`.part`, `.ytdl`, `-Frag…`) и обложка теперь лежат
  в скрытой папке `.ytloader-tmp` внутри папки загрузок и убираются после завершения и при отмене. Пауза и повтор по-прежнему докачивают.
- **Полоса прогресса идёт ровно и только вперёд.** Раньше у HLS-потоков YouTube она стояла на нуле, потом прыгала на 100 %.
  Доля считается по номеру фрагмента, вес дорожек — по размеру из разбора ссылки; просадка счётчика байт при повторе фрагмента
  больше не «закрывает» дорожку.
- **Размер файла точнее.** На YouTube сначала выбираются обычные https-форматы (размер известен точно), а не HLS «Premium»
  (f616), у которого размер — лишь оценка (в приложении было 1,15 ГБ, скачалось ~900 МБ).
- **Отказ 403 посреди загрузки** больше не сразу ошибка: повтор со свежими ссылками, затем запасной набор клиентов YouTube
  (`tv`, `android_vr`, `web_safari`), и только потом обновление yt-dlp и сообщение.
- **Видео открывается в QuickTime.** Кодек по умолчанию — H.264 (раньше «любой» мог отдать VP9/AV1, которые QuickTime не открывает).
  Прежнее значение «любой» из старых настроек заменяется на H.264 один раз; дальше выбор пользователя сохраняется.

## 5.0
Оболочка переписана заново на Swift — теперь её исходники лежат в `host/`.

- **Другие сайты**: VK (в том числе vkvideo.ru), Rutube, Vimeo, Dailymotion, Twitch, TikTok, OK, Dzen, Bilibili, SoundCloud
  и всё остальное, что умеет yt-dlp. Ссылки определяются автоматически; подсказка из буфера обмена работает для известных сайтов;
  в подписи карточки видно, откуда ролик. SponsorBlock и приёмы для JS-проверки применяются только к YouTube.
- **Сборка под Intel**: универсальный DMG (Apple Silicon + Intel) и отдельный `-intel` образ.
- Дубли находятся по ключу ролика, а не по тексту ссылки: `youtu.be/…`, `watch?v=…` и `shorts/…` — это один ролик.
- Прогресс HLS/DASH-потоков (VK, Rutube, Vimeo) учитывает фрагменты, когда размер файла заранее неизвестен.
- Понятные сообщения для ещё нескольких случаев: недоступный формат, нет места на диске, прямой эфир, регион.
- Сломанная запись в очереди или истории больше не убивает всю очередь.
- Тесты (модульные и сквозные с настоящим yt-dlp) и CI на macOS.
